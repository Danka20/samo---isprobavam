# QA Zadatak za Intervju - Testiranje E-commerce Aplikacije

U ovom repozitorijumu se nalazi rešenje tehničkog zadatka za poziciju QA.

## Sadržaj Repozitorijuma
* **`Test_Scenariji_i_Casi.xlsx`** — Sadrži napisane test scenarije i detaljne test kejs-ove za proces kupovine i prijave na sistem.
* **`Bug_Report_Log.docx`** — Dokument sa detaljno opisanim pronađenim greškama, koracima za reprodukciju i ocenom ozbiljnosti (Severity/Priority).

## Opis Rešenja
U okviru zadatka pokrivene su sledeće funkcionalnosti:
1. Registracija i prijava novog korisnika.
2. Dodavanje proizvoda u korpu i pretraga.
3. Proces plaćanja i validacija kupovine u bazi.
